# Home

## Purpose

Document the intended current home page and its simplification rules.

## Route

- Page: `/`
- Source: `app/page.tsx`
- Main styling: `app/globals.css`

## Core structure

The home page should stay very simple and contain only three main elements:

1. Quizzer
2. slogan
3. two actions: join quiz and create quizzes

## Slogan

- Recommended line: **Start fast. Play together.**

## Content rules

### Brand block

- Show the Quizzer name clearly.
- Show a short, simple slogan under it.
- Avoid extra marketing sections, feature grids, or dense explanation.

### Join quiz

- Show a join-code input.
- Show a join action next to or directly attached to the input.
- Keep this as the primary action on the page.

### Create quizzes

- Show a clear login path for quiz creation.
- Keep this secondary to joining a quiz.
- Avoid adding extra host complexity on the home page.

## Behavior rules

- The page should feel immediate and low-friction.
- Joining a quiz should require only code entry and join.
- Creating quizzes should begin with login.
- Any supporting copy should stay minimal.

## Scope boundary

This file documents the intended current home-page structure and rules, not a future proposal lane.
