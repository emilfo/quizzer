# Broadcast Night keyframes

Static keyframe sheets for Lane 2.

## Files

- `index.html` — open this in a browser to review all 10 sheets
- `styles.css` — page composition and lane styling
- `tokens.css` — shared design tokens and palette
- `manifest.json` — export map for screenshot automation

## Export targets

1. `01-entry-sheet.png`
2. `02-host-dashboard-sheet.png`
3. `03-host-editor-sheet.png`
4. `04-host-live-sheet.png`
5. `05-player-join-sheet.png`
6. `06-player-live-sheet.png`
7. `07-projector-lobby.png`
8. `08-projector-question.png`
9. `09-projector-results.png`
10. `10-projector-finished.png`

Each target maps to one top-level `<section>` with a stable `id` and `data-export` attribute.
