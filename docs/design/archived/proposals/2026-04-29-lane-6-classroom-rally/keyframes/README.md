# Lane 6 Classroom Rally — keyframes

Static low-fi visual artifact set for the feedback-driven future-direction lane.

## contents

- `index.html` — single-page keyframe board with 10 screenshot targets
- `styles.css` — classroom-friendly, playful presentation system
- `tokens.css` — shared design tokens and color palette
- `manifest.json` — export metadata and coverage notes

## notes

- No JavaScript is required.
- Projector carries questions and answers; players see only large color-tap targets.
- Results include per-option graph treatment and top-3 movement treatment.
- Color direction is playful and bright, with less orange and more mint / cyan / violet / lime.
