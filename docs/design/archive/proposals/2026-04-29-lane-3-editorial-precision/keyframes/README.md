# Lane 3 — Editorial Precision keyframes

Static HTML/CSS artboards for the Lane 3 proposal.

## What is here

- `index.html` — self-contained preview with 10 export sheets
- `styles.css` — layout, surfaces, and editorial treatment
- `tokens.css` — shared visual tokens
- `manifest.json` — sheet/export metadata for automation

## Capture notes

- Each export sheet is one `<section>` with a stable id and `data-export` filename.
- Use the sections in document order for screenshots.
- No JavaScript is required.
