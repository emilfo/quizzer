# Lane 4 Modular Lab — keyframes

Static low-fi visual artifact set for the selected proposal direction.

## contents

- `index.html` — single-page keyframe board with 10 screenshot targets
- `styles.css` — lane-specific layout and presentation rules
- `tokens.css` — shared design tokens and color system
- `manifest.json` — export metadata and state coverage

## notes

- No JavaScript is required.
- All canonical surfaces and states are represented across the 10 sheets.
- Lane 4 is the base system; the visuals borrow hierarchy, recovery, reveal, and warmth traits from the other lanes without changing the product flow.
