# Quiet Control Room — keyframes

Static, self-contained visual artifacts for Lane 1.

## Contents

- `index.html` — 10 screenshot-ready keyframe sheets
- `styles.css` — lane-specific layout and component styling
- `tokens.css` — shared color, spacing, and type tokens
- `manifest.json` — stable sheet metadata for automation

## Mapping

Each `<section>` in `index.html` has a stable `id` and `data-export` filename that matches the manifest.

## Screenshot notes

- No JavaScript is required.
- Open `index.html` directly in a browser.
- Capture each section by its stable export filename or section id.
