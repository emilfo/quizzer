# Plan template

## 1. objective

State the outcome in one sentence.

## 2. scope

List included deliverables and explicit out-of-scope items.

## 3. constraints

List repo constraints, product invariants, and validation boundaries.

## 4. steps

Describe the smallest useful execution slices in order.

## 5. acceptance criteria

List the observable conditions that define done.

## 6. verification

List the scripts, commands, or manual checks required.

## 7. follow-ups

List deferred work, risks, or open decisions.
